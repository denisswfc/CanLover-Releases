# CanLover-Releases

Releases and website of **[CanLover](https://canlover.mcv-sw.com/)**, a modern, lightweight CAN bus analyzer for Linux and Windows — a free alternative to Vector CANalyzer and PEAK PCAN-View, with native SocketCAN, DBC/SYM decoding, J1939, signal plots and more.

- Website: https://canlover.mcv-sw.com/
- Downloads: https://canlover.mcv-sw.com/releases.html
- User manual: https://canlover.mcv-sw.com/documentation.html
- Community: https://canlover.mcv-sw.com/community.html
